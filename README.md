# ConfigRE

ConfigRE is a configurable requirements engineering framework that extends the OpenRE-Bench/QUARE experimental setting with dynamic agent selection. It selects domain-relevant agents before requirements modeling, negotiation, verification, and software-material generation, then records reproducible artifacts for cross-domain evaluation.

The implementation keeps compatibility with the original OpenRE-Bench artifact contract while adding ConfigRE-specific Phase 0 agent selection and configurable agent strategies.

## Key Features

- Dynamic Phase 0 agent selection with LLM-assisted relevance scoring and fallback metadata.
- Configurable fixed, domain-optimized, full-agent, and automatic-selection experiment settings.
- QUARE-compatible phase artifacts for initial models, negotiation traces, integrated KAOS models, verification reports, and software materials.
- Cross-domain evaluation utilities for ASP, ASR, DFS, conflict noise, BERTScore, and token usage.
- Reproducibility metadata for model settings, seeds, selected agents, fallback flags, and artifact paths.

## Repository Layout

- `src/openre_bench/` contains the executable ConfigRE implementation. The module name is retained for compatibility with the original benchmark code.
- `experiments/` contains ConfigRE experiment scripts, ground-truth relevance labels, and final summarized results.
- `legacy_results/` contains historical QUARE, MARE, iReDev summaries and prior OpenRE-Bench reports retained for baseline reference.
- `data/` contains case-study and ground-truth data used by the benchmark.
- `tests/` contains regression coverage for pipeline utilities and runtime behavior.
- `docs/` contains supporting technical notes.

## Installation

```bash
uv sync --all-groups
```

ConfigRE uses OpenAI-compatible LLM inference through `litellm`. Provide credentials with either:

- `OPENAI_API_KEY`
- `.api_key`
- `.env` based on `.env.example`

Do not commit real API keys.

## Quick Checks

```bash
uv run configre --version
uv run configre --check-openai
uv run ruff check .
uv run pytest
```

The legacy command remains available for compatibility:

```bash
uv run openre_bench --version
```

## Running A Case

```bash
uv run configre --run-case \
  --case-input data/case_studies/ATM_input.json \
  --artifacts-dir artifacts/atm-run \
  --run-record artifacts/atm-run/run_record.json \
  --system quare
```

Key generated artifacts include:

- `phase0_agent_selection.json`
- `phase0_external_spec_rules.json`
- `phase1_initial_models.json`
- `phase2_negotiation_trace.json`
- `phase3_integrated_kaos_model.json`
- `phase4_verification_report.json`
- `phase5_software_materials.json`
- `run_record.json`

## Reproducing The ConfigRE Tables

Run the configuration comparison matrix:

```bash
bash experiments/run_config_comparison.sh
python experiments/compare_results.py
```

Generated and final summarized results are stored in:

- `experiments/results/comparison_summary.csv`: regenerated by `experiments/compare_results.py`
- `experiments/results/comparison_summary_paper_final.csv`: frozen paper-final values; this file is not overwritten by the aggregation script

The current paper tables use these columns:

- Agent-selection metrics: `asp_mean`, `asr_mean`, `dfs_mean`
- Cross-domain comparison metrics: `n_agents_mean`, `dfs_mean`, `conflict_noise_rate_mean`, `bertscore_mean`, `total_tokens_mean`

Ground-truth domain relevance labels are stored in:

- `experiments/ground_truth/domain_relevance.json`

For detailed reproduction notes, see `docs/reproducibility.md` and `experiments/README.md`.

## Artifact Policy

The repository is intended to upload source code, experiment scripts, labels, final ConfigRE summary files, and compact legacy baseline summaries. Per-run phase outputs, logs, caches, API keys, and other intermediate artifacts are excluded by `.gitignore`.
